怎么用

  1. 打开播放器 → 进入「设置」→「配置地址」（有的版本叫「接口」或「订阅」）。
  2. 粘贴上面第一个地址（主入口），保存。
  3. 回到首页，如果弹出仓库列表，选「WKC 自有聚合」。
  4. 点「点我切源」进入片单；搜索时结果里的 [N源] 表示有 N 个上游都有这部片。

首次加载如果空白，退出重进一次即可——播放器需要先下载一次插件。

主入口地址不用换，仓库一更新它就是新的。要是你发现它拿到的还是旧版本， 用下面「固定版本」那个地址——它逐字节冻结、发布即生效。npm 的 @latest 地址（cdn.jsdelivr.net/npm/wkc0001-tvbox-independent@latest/dc.json） 同样不用换，但 jsDelivr 缓存的是 npm 的版本别名，新版可能要过一段时间才通过它生效。

每个来源名后面都带 ⚠勿信广告。这不是装饰：聚合里的上游会在播放过程中插广告， 其中一部分是博彩类。这个提示的意思是「播放器里出现的任何广告、二维码、客服，都不要理」。

关于广告和成人内容

成人内容：在构建阶段筛掉，不在客户端筛。判据是「该来源的分类表里只要出现成人分类，整站不收录」—— 所以你在列表里抽查不到这类分类。已经因为这个原因排除了两个来源。

博彩广告：抽取视频帧做文字识别，命中博彩关键词的来源不收录。 剩下的来源仍然可能在播放中插广告——这是采集站本身的商业模式，客户端拦不住，只能提示。

直播卡顿：每条线路都实测了「下载速度比」（已下载切片能播多久 ÷ 实际花了多久）， 低于播放速度的线路不排序在前。这类指标只能回答"会不会卡"，不能回答"画质好不好"。
